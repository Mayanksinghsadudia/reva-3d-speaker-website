# REVA 3D Speaker Experience

An interactive 3D Exploding Speaker Web Application built with HTML5, CSS3, Tailwind CSS, and HTML5 Canvas frame-by-frame 3D animation engines.

## 🌐 Live Demo & Repository
- **GitHub Repository**: [https://github.com/mayanksinghsadudia/reva-3d-speaker-website](https://github.com/mayanksinghsadudia/reva-3d-speaker-website)
- **Live Published Link**: [https://mayanksinghsadudia.github.io/reva-3d-speaker-website/](https://mayanksinghsadudia.github.io/reva-3d-speaker-website/)

## 🌟 Key Features

- **Interactive 3D Speaker Explode Canvas**: Click the main REVA speaker in the Hero section to explode all 3D acoustic hardware components in real-time.
- **Product Description Woofer Explosion**: Dedicated disassembled 3D anatomical view of the REVA Woofer Speaker Assembly.
- **SONY-Inspired Vector Typography Logo**: Clean corporate typography for the REVA brand.
- **Song Test Audio Player**: Unified audio player showcasing REVA acoustic clarity with synchronized sound wave visualizers.
- **Pure Pitch Black Theme**: Sleek, studio-grade aesthetic (#050505) tailored for high-end audio hardware.

## 🚀 Local Run

```bash
python -m http.server 8080 --directory .
```
Then open `http://localhost:8080/index.html` in your browser.
